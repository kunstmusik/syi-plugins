# Factory controls and preset validation

The [voice fixture](fixtures/voice.blue) retains six synth definitions, their
factory/custom presets and the widget metadata needed to resolve stored
controls. It is a test input, not a composition or a new preset format.

## Stored controls

Dropdown settings store item IDs. An ID must be resolved against the owning
synth's item list; copying another synth's IDs can recall a different waveform,
PWM mode or trigger mode even when the displayed numeric panel values look
correct. Treat labels, numeric branch values and IDs as separate pieces of the
same preset contract.

[check_juno60_presets.py](experiments/check_juno60_presets.py) validates 116
saved presets, including 56 factory patches and 1,512 transcribed reference
settings, control ranges, dropdown references and panel/parameter consistency.
The [factory table](experiments/juno60_factory_reference.csv) is retained as
reference input. Preset audit and full-render records are generated by
[preset checks](experiments/check_juno60_presets.py) and
[voice checks](experiments/check_juno60_voice.py) under `build/research-results/`.
Passing these checks establishes data integrity, not hardware timbre accuracy.

Brass uses Auto, rate 5, delay 6.5, DCO depth 1.5 and VCF depth 0. Its
modulation depends on caller rate/depth/trigger laws. PWM uses raw LFO rather
than delayed vibrato. Raw ENV still reaches VCF/PWM when VCA mode is Gate.
See the [LFO](JUNO_LFO_RESEARCH.md), [PWM](JUNO_PWM_RESEARCH.md) and
[envelope](JUNO_ENVELOPE_AUDIT.md) notes for those execution contracts.

## Factory tape evidence

The bank-A cassette decoder independently validates framing, sequence and all
64 checksums. Patch 78's stored bytes include FREQ=35, ENV=103, KEY=255, RES=255,
A=31, D=179, S=0, R=192 and LEVEL=221; DCO noise/sub/PWM/DCO-LFO and VCF-LFO
are zero. Switch bytes 236/160 are retained without assuming a complete
interpretation; published HPF assignments conflict with the card-derived table.

These bytes describe ADC/DAC control voltages, not physical slider percentages.
Dividing by 255 and replacing card values ignores pot loading and the
voltage/current transfer. The [decoded byte table](experiments/juno60_drum_pitch/factory_bank_A_bytes.csv)
and [tape metadata](experiments/juno60_drum_pitch/factory_tape.json) preserve the
capture hash and limitations. [decode_juno60_factory_tape.py](experiments/decode_juno60_factory_tape.py)
requires that independently supplied source recording.

## Sources

- [Roland owner's manual](https://cdn.roland.com/assets/media/pdf/JUNO-60_OM.pdf), factory cards and control meanings.

Factory performances have unknown note events, gain and processing. Use them
for constrained spectral/attack comparisons rather than absolute loudness
normalization or a unique global envelope fit.
